KOTATSU 利用規約・プライバシーポリシー・違反ガイドライン

最終改定: 2026年8月16日 ／ 運営: KOTATSU運営事務局（以下「当社」）

本規約は、当社が提供するウェブメディア「KOTATSU（コタツ）」（PWA・関連APIを含み、以下「本サービス」）の 利用条件、個人情報の取扱い、および違反行為への対処を一体として定めるものです。 アカウント登録、コメント投稿、URL投稿による記事生成その他本サービスの利用をもって、本規約に同意したものとみなします。

第1部 利用規約

第1条（本サービスの内容）

本サービスは、動画・ライブ配信・SNS投稿等の公開情報をもとに、AIを用いて紹介記事を生成・掲載し、 読者を元のコンテンツへ案内するメディアです。記事は出典（元動画・元投稿へのリンク）を明記し、 権利者への送客を目的として運営されます。

第2条（アカウント）

  1. 登録はメールアドレスまたは外部アカウント（Google・LINE・X）で行い、名前はペンネームで構いません。
  2. 登録情報は正確に保ち、アカウントの管理責任は利用者が負うものとします。
  3. 1人が複数アカウントを不正な目的で使用することを禁止します。

第3条（URL投稿による記事生成）

  1. 利用者は動画等のURLを投稿することで、AIによる紹介記事の生成を依頼できます。記事はおおむね動画10分ごとに1本を目安として自動分割・生成されます。
  2. 生成された記事の本文を利用者が編集することはできません。内容の修正・非公開化・削除は当社（運営）のみが行います。
  3. 生成記事は当社の審査（AIによる事前審査および必要に応じた人による確認）を経て公開されます。当社は理由を通知することなく、公開の可否判断・修正・削除を行うことができます。
  4. 同一動画・同一内容（切り抜き・転載を含む）の重複登録はできません。

第4条（ポイント・報酬）

  1. コメント投稿等の活動でアクティビティポイント（1P=1円換算）が付与されることがあります。
  2. ポイントおよび記事報酬は合算され、合計10,000円に達するごとに銀行振込またはPayPayで精算できます。端数は繰り越されます。
  3. 不正行為（自動投稿・自己循環的なPV操作等）が確認された場合、当社はポイント・報酬を取り消すことができます。

第5条（禁止事項）

利用者は、次の行為をしてはなりません。

  • 「死ね」「殺す」等の脅迫的表現、誹謗中傷、名誉毀損、侮辱にあたる投稿
  • 住所・本名・連絡先等の個人情報の暴露、プライバシー侵害
  • 差別的表現、わいせつな内容、その他公序良俗に反する投稿
  • 著作権・肖像権・商標権その他第三者の権利を侵害する行為
  • 虚偽情報の流布、なりすまし、スパム・宣伝目的の投稿
  • YouTube・X・TikTok・Instagram・Twitch・ニコニコ動画・SHOWROOM・17LIVE・Pococha・radiko等、各プラットフォームの利用規約・ガイドラインに違反する態様での利用
  • 本サービスの運営を妨害する行為、不正アクセス、リバースエンジニアリング

当社は、禁止事項に該当するおそれのある表現を機械的にフィルタリングし、投稿の拒否・保留・削除を行うことがあります。

第6条（知的財産・引用）

  1. 本サービスの記事は、公開情報の紹介・論評を目的とし、出典を明示のうえ必要最小限の引用・埋め込み（各プラットフォーム公式の埋め込み機能）を行います。
  2. 権利者から削除・修正の申立てがあった場合、当社は速やかに対応します（第3部の窓口へご連絡ください）。
  3. 利用者が投稿したコメント等について、利用者は当社に対し、本サービスの提供に必要な範囲で無償で利用（掲載・複製・翻案・要約表示）する権利を許諾するものとします。

第7条（免責）

  1. 記事はAIが公開情報から生成したものであり、内容の完全性・正確性を保証するものではありません。
  2. 当社は、本サービスの利用により利用者に生じた損害について、当社に故意または重過失がある場合を除き、責任を負いません。
  3. 本サービスは予告なく内容の変更・停止・終了を行うことがあります。

第8条（規約の変更・準拠法）

当社は必要に応じて本規約を変更でき、変更後の規約は本ページへの掲載をもって効力を生じます。 本規約は日本法に準拠し、本サービスに関する紛争は東京地方裁判所を第一審の専属的合意管轄裁判所とします。

第2部 プライバシーポリシー

1. 取得する情報

  • 登録情報: メールアドレス、ペンネーム、外部アカウントの識別子（Google・LINE・X）
  • 精算情報: 銀行口座、PayPay ID（報酬の振込にのみ使用）
  • 利用情報: 閲覧・いいね・コメント等の利用履歴、Cookie・localStorage、プッシュ通知の購読情報（端末単位）

2. 利用目的

  • 本サービスの提供・改善、記事のレコメンド、通知の配信
  • ポイント・報酬の計算と精算、不正防止
  • お問い合わせ・権利申立てへの対応

3. 第三者提供・委託

法令に基づく場合を除き、本人の同意なく個人情報を第三者へ提供しません。 ホスティング・データベース・AI処理等の業務委託先（Vercel、Supabase、Anthropic等）には、 目的の達成に必要な範囲でのみ取り扱わせます。

4. 保存期間・開示等の請求

個人情報は利用目的に必要な期間保存し、退会後は法令上必要な範囲を除き遅滞なく削除します。 開示・訂正・削除・利用停止のご請求は第3部の窓口までご連絡ください。本人確認のうえ、法令に従い対応します。

第3部 違反ガイドライン・申立て窓口

1. 違反への措置

禁止事項への違反が確認された場合、当社は違反の程度に応じて次の措置を段階的または即時に行います。

  1. 投稿の非公開化・削除、リスク箇所の修正
  2. 警告、機能（コメント・URL投稿）の利用制限
  3. アカウントの停止・削除、ポイント・未払報酬の没収
  4. 悪質な場合は関係機関への通報・法的措置

2. 権利者・利用者からの申立て

記事・コメントに関する削除依頼、権利侵害の申立て、個人情報に関するご請求は、 運営窓口（ishizawa@epoch-inc.jp）までご連絡ください。 原則として7営業日以内に一次回答します。
